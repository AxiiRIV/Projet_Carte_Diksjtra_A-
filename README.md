# Projet_Carte_Diksjtra_A-
===============================================================================
## Présentation :
Projet réalisé avec mon collègue de classe Wyatt en BUT informatique première année (Semestre 2) pour la SAE S2.02 (Exploration Algorithmique d'un problème). Ce projet met en avant une carte de la Rhune avec une illustration codée utilisant des algorithmes mathématiques pour trouver un meilleur chemin par des sommets et des chemins (théorie des graphes).
=============================================================================

## Comment il marche ? : 
1 : LOGICIEL A UTILISER : 
  - Ce Projet est à utliser sur SPYDER (outil de traitement de données sous        python)

2 : DOSSIERS QUI ACCOMPAGNE LE PROJET DikjAsrt.py : 
  - 1 : laRhune.png : sert de carte de base pour le projet.
  - 2 : graphics.py : bibliothèque nécéssaire à l'affichage du graphe
  - 3 : graphics.pdf : documentation de cette même bibliothèque.
  - 4 : dossier _pycache_ : contien un fichier pour initialiser correctement           graphics.py


  - Ce code n'est pas open source pour l'instant.
